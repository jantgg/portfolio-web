# Portfolio V2

Nueva versión del portfolio de Juan Antonio Gómez Gil, centrada en cómo investiga, conecta sistemas y convierte problemas ambiguos en soluciones que se pueden construir.

La experiencia está disponible en español (`/es`) e inglés (`/en`), con temas oscuro y claro beige persistentes.

## Desarrollo

```bash
npm install
npm run dev
```

La documentación de producto, auditoría, diseño y reconstrucción está en [`docs/`](./docs/README.md).

## Verificación

```bash
npm run lint
npm run typecheck
npm run build
```

La V2 se desarrolla en la rama `v2`. La versión anterior permanece en `main` como referencia visual e histórica.
